This page uses the HTML5 canvas and JavaScript to create a random Spirograph pattern. Select the button to generate a new design.

x = (R + r) cos(t) - (r + O) cos(((R + r) / r)t)

y = (R + r) sin(t) - (r + O) sin(((R + r) / r)t)

R is the fixed outer-circle radius, r is the rotating inner-circle radius, O is the pen offset, and t increases as the pattern is drawn.
