Research Sources

These sources provide information about each CMS's support, technology, capabilities, limitations, and example websites.

WordPress

  • WordPress Official Website - Open source support, themes, block editing, and plugins.
  • WordPress Requirements - PHP and database requirements.
  • Hardening WordPress - Security risks, plugin maintenance, and updates.
  • High Traffic Tips for WordPress - Plugin and theme database usage, server load, and performance limitations.
  • NASA WordPress Showcase - Identifies NASA as a website that uses WordPress.

Drupal

  • About Drupal - Community support, content management, modules, and themes.
  • Drupal System Requirements - Server and database requirements.
  • Drupal Upgrade Status - Deprecated code, extension compatibility, and major version upgrade requirements.
  • Mobomo Drupal Case Studies - Includes the General Services Administration's USA.gov website.

Joomla

  • Joomla Official Website - Open source project and support information.
  • Joomla 5 Technical Requirements - PHP and supported database requirements.
  • Joomla Benefits and Core Features - Multilingual content, access controls, templates, and extensions.
  • Joomla 5 to 6 Upgrade Guide - Third party extension compatibility and backward compatibility restrictions.
  • Joomla Showcase Directory - Example websites, including Vokoloko.cz.

Ghost

  • Ghost Official Website - Open source publishing, managed hosting, newsletters, and memberships.
  • Ghost Ubuntu Installation Guide - Production requirements, including Node.js, MySQL, and NGINX.
  • Ghost Developer Documentation - APIs, integrations, and custom front ends.
  • Ghost Alternative Payment Gateways - Native Stripe support and requirements for using other payment providers.
  • Ghost for Publishers - Publisher examples, including 404 Media.

Grav

  • Grav Official Website - Support, flat file content storage, templates, plugins, and features. The website also identifies itself as built with Grav.
  • Grav Performance and Caching - Page change detection, PHP caching, and filesystem performance limitations.
