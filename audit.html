Mobile Homepage Design

I chose to use a responsive interface rather than creating a separate mobile homepage. The same HTML page provides the content and navigation for both desktop and mobile visitors.

  • The viewport meta tag sets the layout viewport to the device width.
  • CSS media queries stack the hero content and assignment cards into one column on small screens.
  • The mobile navigation displays the same four menu choices vertically: About Me, My Assignments, Skills, and Resources.
  • The homepage image scales within its container.
  • Standard HTML links provide navigation without a custom JavaScript menu.

I checked the homepage in Chrome's responsive preview at a width of 375 pixels. The navigation links stacked vertically, assignment cards appeared in one column, and all four navigation links reached their matching sections. The page fit within the screen without sideways scrolling.
